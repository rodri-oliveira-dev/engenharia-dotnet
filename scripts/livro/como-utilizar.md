# Como utilizar este livro

Este livro pode ser lido em sequência ou consultado conforme a necessidade.
Os capítulos conectam conceitos, exemplos de código e decisões de engenharia.

## Escolha seu percurso

- **Fundamental:** consolide os conceitos da linguagem e as bases necessárias
  para compreender os exemplos.
- **Intermediário:** avance para aplicações, persistência, integração e
  decisões de projeto.
- **Avançado:** explore os efeitos das decisões em sistemas distribuídos,
  arquitetura, segurança, desempenho e operação.

Os níveis indicados nos capítulos orientam a leitura, não classificam a
experiência profissional do leitor.

## Aprenda com os exemplos

Consulte os objetivos e pré-requisitos de cada capítulo. Compare alternativas,
observe as restrições e procure reproduzir os exemplos nos laboratórios do
repositório. Diferencie código ilustrativo de soluções prontas para produção.

Use o sumário e os links entre capítulos para retomar os fundamentos. Os
apêndices complementam a leitura com compatibilidade de versões e trilhas
de estudo. Os estudos de caso ajudam a relacionar decisões ao contexto.

## Consulte a versão original

O livro é uma edição de um projeto em evolução. O endereço do repositório
está no rodapé; a revisão da edição consta da capa. Use essa identificação
ao relatar problemas ou comparar versões.
